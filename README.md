# Minecraft files

Public download files for the Minecraft-Webpages catalog. Upload files into the matching category folder; the website reads these folders directly and does not use GitHub Releases.

## Folders

- `schematics/` — `.litematic`, `.schem`, `.schematic` files; optional preview images can sit beside them.
- `resource-packs/` — resource/texture packs.
- `shaderpacks/` — shaderpack files.
- `xaero-maps/` — Xaero map exports or backups. Zip a folder before uploading it.
- `modpacks/` — modpack files.

Use GitHub’s **Add file → Upload files** inside the appropriate folder. Files in this public repository are publicly downloadable. Do not upload secrets or private world data.
